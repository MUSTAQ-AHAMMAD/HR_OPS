1. Run the application:
   ```bash
   npm install
   npm run dev
   ```

2. Seed with demo data:
   ```bash
   npm run db:seed
   ```

3. Login with demo credentials:
   - Email: `admin@hrops.com`
   - Password: `Admin@123`

4. Navigate to each page and capture screenshots

5. Save them in this directory with the correct filenames
