## Design System Highlights

### Colors
- **Primary Blue**: #3b82f6 (buttons, links, accents)
- **Success Green**: #22c55e (positive indicators)
- **Error Red**: #ef4444 (errors, warnings)
- **Secondary Gray**: #64748b (text, borders)
- **Background**: #f8fafc (page background)
- **Cards**: #ffffff (white with shadows)

### Typography
- **Headers**: Bold, large (24-48px)
- **Body**: Regular, 16px base
- **Small text**: 14px for metadata
- Inter font family throughout

### Components
- **Buttons**: Rounded, solid colors, hover states
- **Cards**: White background, subtle shadows, rounded corners
- **Icons**: Lucide React icons (consistent 20-24px size)
- **Forms**: Input fields with icon prefixes, focus rings
- **Spacing**: Consistent 8px base unit

### Accessibility
- WCAG AAA contrast ratios
- Focus visible states on all interactive elements
- Semantic HTML structure
- Screen reader friendly
- Keyboard navigation support

---

## Responsive Design

All pages are fully responsive:
- **Mobile**: Single column, stacked cards
- **Tablet**: 2-column grids
- **Desktop**: 3-4 column grids
- **Breakpoints**: 640px (sm), 768px (md), 1024px (lg), 1280px (xl)

---

## Dark Mode Support

The application includes dark mode theme:
- Dark backgrounds (#0f172a, #1e293b)
- Inverted text colors
- Adjusted shadows and borders
- Color variables for easy theming
- Smooth transitions between modes
